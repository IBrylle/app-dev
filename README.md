# My Favorite Series: Stranger Things

**Stranger Things** is a thrilling sci-fi series set in the 1980s.  
It mixes *mystery, friendship, and supernatural adventures* in a small town called Hawkins.

## Why I Like It
- Great characters like Eleven and Dustin
- Exciting story twists
- 80’s nostalgic vibe and music 🎶
